VarCat

Creates Spiral-named Figma Variables as empty shells: pick templates, tick the axes, then Apply writes paths and types only — every value stays yours to fill.

Not ColorCat. ColorCat generates color ramps; VarCat owns naming and bulk creation. This plugin must be built before it loads — run npm run build if the window is blank.
